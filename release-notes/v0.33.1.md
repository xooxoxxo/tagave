**Patch release (0.33.0 → 0.33.1).** Settings say what they do: one name per switch, confirms before anything you can't take back, and no setting that saves differently from how it looks.

## Before you update

- **Nothing to do.** No database change in this release.

## Fixed

- **Allow writes:** a music folder's own switch is now "Allow writes", so it no longer shares a name with Tag writing's library-wide "Tag writes". Tag writing lists only the folders that will really be written. ([f513da5](https://github.com/xooxoxxo/tagave/commit/f513da5))
- **Rescan every** can be changed after a folder is added, and is at least 60 seconds. ([9d21e03](https://github.com/xooxoxxo/tagave/commit/9d21e03), [6dbeeb0](https://github.com/xooxoxxo/tagave/commit/6dbeeb0), [26480d3](https://github.com/xooxoxxo/tagave/commit/26480d3))
- **Asks first:** forgetting the Discogs token, AcoustID key, Jev key or sign-in client secret, cancelling an Autotagger run, revoking an invite link and "Use shared" now ask before they happen. ([aca8501](https://github.com/xooxoxxo/tagave/commit/aca8501))
- **Saving matches the page:** Leave alone sits inside Naming, whose Save covers it; the sign-in service's Join appears once the service is saved. ([73f7d1d](https://github.com/xooxoxxo/tagave/commit/73f7d1d), [36beefa](https://github.com/xooxoxxo/tagave/commit/36beefa))
- **One place for Last.fm:** Settings › Modules › Player keeps the server's Last.fm app key; your own Last.fm connection is in Your settings › Listening. ([dbab7ee](https://github.com/xooxoxxo/tagave/commit/dbab7ee))
- **Setup checklist** uses the same rows as Integrations and Add music folder. ([dd794d6](https://github.com/xooxoxxo/tagave/commit/dd794d6))
- **Editors** no longer see an Edit link to a page they can't open. ([fda1e36](https://github.com/xooxoxxo/tagave/commit/fda1e36))
- **Updates** shows Unknown, None or Not measured instead of a dash. ([b6153d7](https://github.com/xooxoxxo/tagave/commit/b6153d7))
